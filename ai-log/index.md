# sermon-proof — ai-log index

sermon-proof is a local Go tool (stdlib only, embedded vanilla web UI, loopback server) for proofreading sermon transcripts (`.md`, `.vtt`) against their audio and writing the edits back safely. Transcripts come from the sibling project `../語音辨識/`.

Rules for writing and reading logs: [README.md](README.md). Read this index first, then open only the logs relevant to your task.
